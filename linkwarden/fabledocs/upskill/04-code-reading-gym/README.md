# 04 — Code Reading Gym

Reading code precisely is the highest-leverage mid-level skill: reviews, debugging, and interviews are all reading exercises under time pressure. Four workout types, all on real Linkwarden code:

1. [01-annotation-drills.md](01-annotation-drills.md) — 8 excerpts; annotate inputs/outputs/invariants/side effects/failure modes.
2. [02-trace-tables.md](02-trace-tables.md) — 5 value-by-value traces (UI→API, persistence, auth, error, async).
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 8 bad-vs-better pairs mirroring real repo patterns (all fake code labeled).
4. [04-review-katas.md](04-review-katas.md) — 8 fake PRs to review with blocking/important/optional findings.

Method: always predict before you verify. Write your annotation/trace/review *first*, then check against the code and the answer notes. The gap between prediction and reality is the curriculum.
